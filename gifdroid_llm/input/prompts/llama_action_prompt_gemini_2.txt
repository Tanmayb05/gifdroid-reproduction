Your task is to act as a JSON API and convert a list of keyframes into a structured list of actions.

**JSON Schema:**

Your output MUST be a valid JSON array of objects. Each object must conform to the following schema:

```json
{
  "screen_description": "string (required) - A detailed description of the visible UI on the screen. Describe the screen title, main content, buttons, dialogs, etc. Be specific to what you see in the image.",

```

4.  Do NOT include any text, prose, or markdown outside of the JSON array. Your response must start with `[` and end with `]`.
