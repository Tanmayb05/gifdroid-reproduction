💡 KEY CONCEPTS EXPLAINED
═══════════════════════════════════════════════════════════════════════════════

TWO-STAGE ARCHITECTURE:
  Stage 1: Analyze video ONCE → Generate understanding (memory.md)
  Stage 2: Use memory MANY TIMES → Control device (reuses understanding)
  Result: 90% token savings!

WHY IT'S EFFICIENT:
  Traditional: Video → Analyze → Act → Analyze again → Act → ...
  Two-Stage: Video → Analyze → Remember → Act → Act → Act → ...
  Memory reuse is 85% cheaper than re-analyzing video!

MAIN COMPONENTS:
  1. VideoFrameExtractor - Break video into frames
  2. KeyframeSelector - Filter to important frames
  3. LLM Provider - AI analyzes and understands
  4. Memory Parser - Structure output
  5. MemoryToDevice - Use memory to automate
  6. Automation Loop - Keep going until done
  7. Execution Trace - Log everything

MEMORY.MD:
  Human-readable document containing:
  • Task Summary (what we're doing)
  • Steps (sequence of actions)
  • UI Elements (buttons, fields, locations)
  • Completion Criteria (how to know when done)

❓ COMMON QUESTIONS
═══════════════════════════════════════════════════════════════════════════════

Q: What is src_llm?
A: An AI system that analyzes a video once, then reuses that understanding to
   automate Android app tasks. Saves 90% on token costs.

Q: Why two stages?
A: Separation of concerns. Stage 1 (expensive video analysis) runs once.
   Stage 2 (cheap automation) uses that understanding many times.

Q: What's memory.md?
A: A human-readable document containing the task description, steps, UI 
   elements, and completion criteria extracted from the video.

Q: Can I use it offline?
A: Stage 1 (video analysis) can run offline. Stage 2 needs device access.
   For cloud LLMs, you need internet.

Q: Which LLM should I use?
A: Try Qwen 2.5-VL (local, free) or Gemini 1.5 Flash (cloud, free tier).
   See supported models for all options.

Q: How much does it cost?
A: Local models (Ollama) = free. Cloud models have API costs, but 90%
   token savings means huge cost reduction vs alternatives.
