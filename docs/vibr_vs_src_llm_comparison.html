Analysis

src_llm advantages:

  • 25.7× faster due to memory reuse (Stage 1 → Stage 2)
  • Deterministic task execution via LLM context (no retry loops)
  • Lower token usage (fewer but more targeted API calls)
  • Parallel Stage 1/Stage 2 pipelines possible

ViBR advantages:

  • Scene-by-scene replay (maps video frame-by-frame)
  • Explicit state consistency validation per scene
  • Recovery mechanisms for device drift
  • Better for complex, multi-step device interactions

Recommendation: Use src_llm (Stage 1 + 2) for fast, deterministic automation. Use ViBR for frame-accurate bug reproduction where state alignment is critical.
