At a glance

  • Input is a bug video plus a target device/app.
  • The video is split into action scenes like tap, scroll, and input.
  • Each scene is analyzed to find the likely interacted region.
  • The system checks whether the current screen matches the recorded screen.
  • If yes, it executes the action. If not, it explores until the screen matches.
  • This repeats scene by scene until the bug is reproduced or the flow ends.
